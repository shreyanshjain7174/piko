# Roadmap

## v0.1 — the loop
App plus keyboard, arm-and-go, streaming insertion, on-device ASR and cleanup, local history,
four skins. No account, no cloud, no subscription. Free on TestFlight.

Done when: a stranger can install it, arm it once, and dictate a message in a third-party app
without reading instructions.

## v0.2 — the identity
Live Activity, Back Tap and Action Button arming, Control Center control, profile chips,
edit-pair learning, personal lexicon, searchable history. The router ships here — "Do" and
"Recall" modes arrive with it.

Done when: the rewrite quality is visibly better for a two-week user than for a day-one user.
That is the only metric that matters in this release.

## v0.3 — the object
The Pebble accessory, and the opt-in open-weight model download for people who want their own
weights. Only if v0.2 users arm several times a day.

## Not scheduled
iPad, Mac, Android, teams, sync, a chat interface. Each of these is a different product wearing
this one's clothes.
