<objective>
Build the real `Activity<PikoAttributes>` lifecycle: request at arm time (adopting an existing
activity if the process relaunched mid-session), update on every phase change and draft arrival,
end on idle. Keep every ActivityKit call inside one new, App/Piko-only type so `PikoAudio` stays
importable on macOS, and keep the parts that can be tested without a real Live Activity — word
counting and the "update vs end" decision — as pure functions separate from the ActivityKit calls
themselves, per 07-RESEARCH.md's Architectural Responsibility Map and the phase's test-strategy
constraint (a test bundle is not a real app process; real `Activity.request/update/end` calls
cannot be meaningfully asserted on here).

Purpose: LACT-01 needs the Live Activity to exist and reflect armed/capturing/tidying state; this
plan is the container-app side of that (the widget's rendering is Plan 07-03, in parallel — this
plan does not touch anything under `App/PikoWidgets`).

`session.arm()` already proves; the Live Activity's content is kept current by two long-running
`Task`s already-established patterns (mirroring `AppComposition`'s existing signal-forwarding
`Task`); `LiveActivityContent`'s two pure functions are unit-tested on macOS and iOS alike.

Add `enum LiveActivityContent` (a namespace, no instance state) with three static members:

`static func wordCount(in text: String) -> Int` — split `text` on whitespace and newlines,
discarding empty substrings, and return the count. Use `text.split(whereSeparator: { $0.isWhitespace

multi-phase-history logic that is not asked for.

`func start(skin: Skin) async` — first check `Activity<PikoAttributes>.activities.first`
(07-RESEARCH.md Pattern 2: resuming after relaunch). If one exists, assign it to `self.activity`
and return without calling `.request` again — a duplicate request produces two competing Live

non-nil; a failed request must not throw out of `start(skin:)` — arming the microphone session must
succeed regardless of whether the supplementary Live Activity could be created. Set
`self.currentPhase = .armed` and `self.currentWords = 0` unconditionally at the end of this method,
whether adopting or requesting.

`func update(phase: SessionPhase) async` — set `self.currentPhase = phase` first. A real `.idle`
always clears `isTidyingOverride` and ends the Activity: if `LiveActivityContent.shouldEndActivity(for:
phase)`, set `self.isTidyingOverride = false`, call `await end()`, and return. Otherwise call the
shared private `refreshContent()` helper described below.

`func setTidying(_ tidying: Bool) async` — set `self.isTidyingOverride = tidying`. Guard
`self.currentPhase != .idle` and return early if it is idle — a late-arriving
`onTidyingChange(false)` (or an out-of-order `true`) from `CaptureCoordinator.stopCapture()`'s
finalize tail must never resurrect an Activity this controller already ended (e.g. because a
`.stopRequested`-driven `session.disarm()` raced ahead of the rewrite finishing). Otherwise call
`refreshContent()`.

`func updateWords(from text: String) async` — set `self.currentWords =
LiveActivityContent.wordCount(in: text)`, then call `refreshContent()`.

Add a private helper `func refreshContent() async`, called by `update(phase:)`'s non-idle branch,
`setTidying(_:)`, and `updateWords(from:)`: build `PikoAttributes.ContentState(phase:
LiveActivityContent.effectivePhase(sessionPhase: self.currentPhase, isTidying:
self.isTidyingOverride), words: self.currentWords, levels: LiveActivityContent.placeholderLevels())`,
wrap it in `ActivityContent(state:staleDate:)` with a freshly-computed `staleDate:
Date().addingTimeInterval(8 * 3600)` (see the interfaces note on why this must be recomputed, not
cached), and call `await self.activity?.update(content)`. Always compute the displayed phase through
`LiveActivityContent.effectivePhase(...)` — never assign `self.currentPhase` directly into
`ContentState.phase` — that pure function is the only place `.tidying` is ever produced (Task 1),
and bypassing it here would silently reproduce the exact gap this plan exists to close.

`func end() async` — `await self.activity?.end(nil, dismissalPolicy: .default)`, then set
`self.activity = nil`.

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-02-01 | Information Disclosure | Lock Screen `ContentState` | accept | Only a phase label and a word *count* are shown, never the transcript text itself; the user explicitly armed the session that produces this content, matching the existing microphone/background-audio consent model |
| T-07-02-02 | Tampering (data integrity, not security) | `Activity<PikoAttributes>.request` called more than once per session | mitigate | `start(skin:)` checks `Activity<PikoAttributes>.activities.first` before requesting (07-RESEARCH.md Pattern 2), preventing duplicate competing Live Activities |
| T-07-02-03 | Denial of Service | rapid `.draftUpdated` signals driving `activity.update()` calls | accept | Update cadence is bounded by the transcriber's own hypothesis cadence (~1–2/sec, unchanged by this plan); no new polling loop is introduced; real-device throttling behavior is an explicit open verification gap (see `<verification>`) |
| T-07-02-SC | Tampering | dependency installs | mitigate | No package manager runs in this plan; `ActivityKit` is a first-party system framework already present in the iOS 26.0 SDK |
</threat_model>
