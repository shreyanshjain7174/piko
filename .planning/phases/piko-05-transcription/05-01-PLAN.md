**ArmedSession.swift:**
Add `var buffers: AsyncStream<AVAudioPCMBuffer> { get }` to the `ArmedSession` protocol. Keep the existing properties/methods unchanged. Add `import AVFAudio` (needed for `AVAudioPCMBuffer` type).

**SessionCoordinator.swift:**
1. Add private `AVAudioEngine` instance variable (lazy or created in init).
2. Add private continuation and stream for buffers (`AsyncStream<AVAudioPCMBuffer>.Continuation`), using `AsyncStream.makeStream()` pattern matching the existing `phase` stream.
3. Expose `public let buffers: AsyncStream<AVAudioPCMBuffer>`.
4. In `startCapture()`:
   - Configure engine input node format (use `inputNode.outputFormat(forBus: 0)`).
   - Install tap with `inputNode.installTap(onBus: 0, bufferSize: 1024, format: format) { buffer, _ in self.buffersContinuation.yield(buffer) }`.
   - Call `try engine.start()`.
   - Set `currentPhase = .capturing` and yield to phase continuation.
5. In `stopCapture()`:
   - Call `inputNode.removeTap(onBus: 0)`.
   - Call `engine.stop()`.
   - Set `currentPhase = .armed` (existing behavior).
   - Do NOT call `buffersContinuation.finish()` here — the stream stays open for the session lifetime; a new capture reuses it.
6. In `disarm()`:
   - Also remove tap / stop engine if currently capturing.
   - Call `buffersContinuation.finish()` here (session ending).
7. Keep the entire file wrapped in `#if os(iOS)`.

**Concurrency:** `installTap` callback runs on the audio render thread. Only `continuation.yield(buffer)` in the callback — no other work. The continuation is thread-safe per AsyncStream docs.

**Error handling:** Wrap `engine.start()` in do/catch; if it throws, set phase back to `.armed`, remove the tap, and re-throw as `PikoError.sessionInterrupted`.
