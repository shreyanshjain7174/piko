<objective>
Put the Brain on the write path: route the final transcript with the cheap prefilter, clean it under budget, and ship the raw transcript unchanged whenever cleanup cannot deliver.

Purpose: Plan 06-01 built a `rewrite` that can clean text and a budget that can give up. Nothing calls either. `CaptureCoordinator.stopCapture` still writes `shipped: finalText` with a `TODO(phase 6)` next to it. This plan removes that TODO and proves CLNP-03's ordering claim with a test that counts inference calls rather than asserting it in prose.

Output: A capture that ends with cleaned text on a capable device and with the raw transcript everywhere else, plus a measured `brainMS` so Spike 5 has a number to look at.
</objective>

Current `SystemBrain.route` — already prefilter-only, already checks recall before command:
```swift
private static let commandStarters = ["remind me", "set a timer", "add to", "schedule",
                                      "create a", "make a note", "delete", "cancel",
                                      "open ", "text ", "call "]
private static let recallStarters  = ["what did i", "when did i", "find where",
                                      "search for", "show me my", "remind me what"]

public func route(_ text: String) async -> Route {
    let lowered = text.lowercased().trimmingCharacters(in: .whitespacesAndNewlines)
    if Self.recallStarters.contains(where: lowered.hasPrefix) { return .recall }
    if Self.commandStarters.contains(where: lowered.hasPrefix) { return .command }
    return .write
}
```

**`Tests/PikoBrainTests/RoutePrefilterTests.swift`:**
Swift Testing, `@testable import PikoBrain`, `import PikoKit`. No platform guard.

Test 1 is the CLNP-03 proof and is the reason this task exists. Build a counter that survives concurrency:

```
final class CallCounter: @unchecked Sendable {
    private let lock = NSLock()
    private var value = 0
    func increment() { lock.lock(); value += 1; lock.unlock() }
    var count: Int { lock.lock(); defer { lock.unlock() }; return value }
}
```

Construct `SystemBrain(inference: { _, _ in counter.increment(); return "" })`, call `route` over at least a
dozen phrases spanning all three routes, then `#expect(counter.count == 0)`. This is a real proof: if anyone
later wires the rewrite model into routing, the injected closure fires and the test fails. A test that only
asserts the returned `Route` values would not catch that.

**`App/Piko/CaptureCoordinator.swift`:**
Add `import PikoBrain` is *not* needed — `CaptureCoordinator` should depend on the `Brain` protocol from
`PikoKit`, not on the concrete `SystemBrain`. Add a stored `private let brain: any Brain` and a `brain:`
parameter to `init`, placed after `transcriber:`.

Replace the tail of `stopCapture()`:

1. `let finalText = await transcriber.finish()`
2. `let profile = channel.readState()?.profile ?? .message` — the keyboard owns profile selection (CONSTRAINTS
   C7 means it cannot infer the host app), and `SessionState` already carries it. Hardcoding `.message` here
   would quietly discard the user's choice.
3. `let route = await brain.route(finalText)`
4. Start a `ContinuousClock.Instant` before the rewrite, and compute elapsed after it.
5. `let shipped = (try? await brain.rewrite(finalText, profile: profile, lexicon: [], examples: [])) ?? finalText`

   The `try?` is the entire graceful-skip mechanism required by CLNP-02, and it deliberately collapses every
   Brain failure — budget exceeded, device not eligible, Apple Intelligence off, guardrail refusal — into the
   same outcome: ship what the transcriber heard. There is no user-visible failure because there is no failure
   path; the raw transcript was always going to be acceptable output.

   Rewrite regardless of `route`. v0.1 has no command or recall handler, so a command-shaped utterance still
   gets inserted as text and still deserves cleaning. `route` is recorded on the result for v0.2 to act on, not
   branched on here.

6. Convert the elapsed `Duration` to milliseconds with
   `Int(elapsed.components.seconds * 1000 + elapsed.components.attoseconds / 1_000_000_000_000_000)` and pass it
   as `timings: .init(brainMS: brainMS)`. `firstWordMS` and `transcribeMS` stay at their defaults — Phase 5 did
   not measure them and this plan does not start.
7. Build `CaptureResult(raw: finalText, shipped: shipped, route: route, profile: profile, timings: ...)`, then
   `channel.writeResult(result)` and `channel.post(.resultReady)` as before.

Do not publish `SessionPhase.tidying` here. `SessionCoordinator` owns phase and republishes `currentPhase` on a
~2 s heartbeat, so a 600 ms tidying window written directly to the channel would race that heartbeat and mostly
not be seen. Doing it properly needs a phase-ownership API on `SessionCoordinator`, which is out of scope for
CLNP-01/02/03. Record it in the summary as a deliberate deferral so it is not lost — `PikoFace` and `MicButton`
already render `.tidying` and currently never see it.
