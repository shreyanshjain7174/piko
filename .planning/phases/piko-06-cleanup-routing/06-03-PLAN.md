From `Sources/PikoKit/Contracts.swift` — the enum to extend, and the only `switch` over it in the codebase:
```swift
public enum Profile: String, Codable, Sendable, CaseIterable {
    case message, email, note, code

    public var styleHint: String {
        switch self {
        case .message: "Short and casual. Contractions fine. No greeting or sign-off."
        case .email:   "Polite and complete. Greeting and sign-off if the speaker implied one."
        case .note:    "Terse. Fragments fine. No pleasantries."
        case .code:    "Imperative mood, present tense, conventional-commit shape when it reads like a commit."
        }
    }
}
```

`styleHint` reaches the model through this, unchanged, in `Sources/PikoBrain/SystemBrain.swift`:
```swift
4. Match this tone: \(profile.styleHint)
```

The draft `.agent` instruction text, quoted verbatim from `docs/SPEC.md`:
> "Imperative, unambiguous, no filler words or hedging. State the concrete file/symbol/action if the speaker
> named one. No greeting, no pleasantries, no restating the obvious."
