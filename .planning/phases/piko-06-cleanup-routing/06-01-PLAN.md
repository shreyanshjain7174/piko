**`Sources/PikoBrain/RewriteBudget.swift`** (new file, no platform guard — this must compile on macOS):
Add an internal generic helper:

```
func withRewriteBudget<T: Sendable>(_ budget: Duration,
                                    operation: @escaping @Sendable () async throws -> T) async throws -> T
```

Implement it with `withThrowingTaskGroup` over a private `enum BudgetRace<T: Sendable>: Sendable { case finished(T); case expired }`,
following the house pattern quoted in `<interfaces>`:
- child A runs `operation()` and returns `.finished(value)`
- child B runs `try await Task.sleep(for: budget)` and returns `.expired`
- take `try await group.next()`, then `group.cancelAll()` before returning or throwing
- `.finished` → return the value; `.expired` → throw `PikoError.brainBudgetExceeded(milliseconds:)`
- if `operation()` throws, `group.next()` rethrows it — let that propagate untouched (Test 4)

Convert `Duration` to milliseconds for the error payload with:
`Int(budget.components.seconds * 1000 + budget.components.attoseconds / 1_000_000_000_000_000)`.

Correctness note to encode as a comment in the file, because it is the whole reason this helper exists: a task
group awaits its remaining children when the body's scope exits, so a slow child that ignores cancellation would
delay the thrown error past the budget. `group.cancelAll()` before returning is what keeps that from happening,
and Test 3 is what proves it. `Task.sleep` and `LanguageModelSession.respond(to:)` are both cancellable.
If `respond` is ever observed on device to ignore cancellation, the escalation is a detached task plus
`withCheckedThrowingContinuation` — do not build that now, there is no evidence it is needed.

**`Sources/PikoBrain/FoundationModelsInference.swift`** (new file, entirely inside `#if os(iOS)`):

Match the platform-guard shape Phase 5 established for `SpeechTranscriberEngine`: iOS-only file, so macOS
`swift build` never sees the framework. `Package.swift` declares `.macOS(.v15)` while FoundationModels needs
macOS 26, so an unguarded import would break the macOS build the project relies on.

```
#if os(iOS)
import FoundationModels

@available(iOS 26.0, *)
enum FoundationModelsInference {
    static func run(instructions: String, prompt: String) async throws -> String
}
#endif
```

`run` does, in order:
1. `let model = SystemLanguageModel.default`
2. `switch model.availability` — `.available` falls through; `.unavailable(let reason)` throws
   `PikoError.brainUnavailable(...)` with a distinct string per reason. Handle all three reasons
   (`deviceNotEligible`, `appleIntelligenceNotEnabled`, `modelNotReady`) and add `@unknown default:`,
   because `UnavailableReason` is not `@frozen` even though `Availability` is.
3. `let session = LanguageModelSession(instructions: instructions)` — the `String?` instructions initialiser
   is real and `@_disfavoredOverload`; passing a `String` selects it.
4. `let options = GenerationOptions(sampling: .greedy)` — greedy sampling is deterministic, which is the
   anti-hallucination knob `docs/MODELS.md` demands. Do not also pass `temperature`; greedy makes it
   meaningless. Do not set `maximumResponseTokens`: a truncated rewrite silently loses the speaker's words,
   which is a worse failure than a slow one, and latency is already bounded by the budget.
5. `let response = try await session.respond(to: prompt, options: options)`
6. return `response.content.trimmingCharacters(in: .whitespacesAndNewlines)`

Wrap steps 3-6 in `do/catch` over `LanguageModelSession.GenerationError` and rethrow as
`PikoError.brainUnavailable("<case name>: <context.debugDescription>")` so callers only ever see one error
family. `guardrailViolation` and `refusal` are included in that mapping deliberately — a refused rewrite must
degrade to the raw transcript, never surface as a user-facing error.

Do not call `prewarm`. Its benefit is unmeasured (06-RESEARCH.md assumption A3, Spike 5 has not run), and using
it usefully means caching a `LanguageModelSession` across `startCapture`/`stopCapture`, which adds mutable
cross-call state and an instructions-keyed invalidation rule to buy an unquantified win. Plan 06-02 records
`brainMS` so that decision can later be made with numbers. Note the deferral in the summary.
